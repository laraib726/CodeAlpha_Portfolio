# CodeAlpha - Personal Portfolio Website (Task 3)

This is a responsive and modern personal portfolio website built as **Task 3** for the CodeAlpha Frontend Web Development Internship. It showcases my web development skills, projects, and professional background.

## Features

* **Responsive Design:** Looks great on both mobile phones and desktop computers.
* **Hero Section:** Features a clean introductory banner with my name, role, and quick action buttons.
* **Projects Showcase:** Displays various frontend projects with titles, descriptions, and interactive elements (including Café Nest, Avengers Gallery, Book Image Gallery, Login page, Frontend Skill Quiz and Calculator).
* **Downloadable Resume:** Includes a direct button to download or view my professional CV (`CV.pdf`).
* **Social Links:** Direct clickable links to my GitHub and LinkedIn profiles using custom SVG icons.

## Technologies Used

* **HTML5** (Structure and layout)
* **CSS3** (Styling, custom dark theme, and grid layouts)
* **Git & GitHub** (Version control and deployment)
* **JavaScript** (Interactive features and UI handling)
