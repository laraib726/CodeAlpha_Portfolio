# CodeAlpha - Image Gallery (Task 1)

This project is a fully interactive and responsive **Image Gallery** developed for the **CodeAlpha Frontend Development Internship**.

## 📌 Features & Requirements
- **HTML & CSS Layout:** Clean grid structure designed for visual book collection ("Book's Hunter").
- **JavaScript Navigation:** Interactive Lightbox modal view with Next (❯) and Previous (❮) navigation buttons.
- **Hover Effects:** Smooth transition animations and dynamic hover styles on book cards.
- **Responsive Design:** Fully optimized across different screen sizes and mobile devices.
- **Dynamic Category Filtering (Bonus):** Instant category filtering for English, Novels, Motivational, Dramas, and Stories.

## 🛠️ Built With
- **HTML5**
- **CSS3** 
- **JavaScript**
