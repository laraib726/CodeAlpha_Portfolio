# DecodeLabs Internship - Project 2: Café Nest Website

A modern, responsive dark-themed landing page designed for a coffee shop and bakery.

## 🌟 Key Features
- **Dark Gold/Amber Aesthetic:** Modern dark slate theme with glowing accents.
- **Responsive Navigation:** Smooth sticky header with scroll-padding offset.
- **Hero Banner:** Smooth fade-in entrance animations and dual CTA buttons.
- **Interactive Menu Gallery:** Smooth hover zoom effects and glowing card highlights.
- **Contact Section:** Clean grid layout with location branch card and interactive form.
- **Mobile Friendly:** Fully optimized for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Custom Animations)
