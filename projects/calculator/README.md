# CodeAlpha - Calculator (Task 2)

This project is developed as part of **Task 2: Build a Calculator** for the **CodeAlpha Frontend Development Internship**.

It is a responsive, web-based calculator designed with a clean and eye-friendly dark theme.

## 🚀 Features
- **Basic Arithmetic Operations:** Addition (+), Subtraction (-), Multiplication (*), Division (/).
- **Control Features:** All Clear (AC) to reset the display and Delete (DEL) to remove the last entered digit.
- **User Interface:** Clean, responsive grid layout designed with eye-friendly soft colors.

## 🛠️ Technologies Used
- **HTML5:** Page structure and input layout.
- **CSS3:** Responsive Grid layout, styling, and color themes.
- **JavaScript (ES6):** Dynamic calculation logic and display updating.
